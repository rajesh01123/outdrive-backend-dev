# Driver API Documentation

No driver API is implemented in the current authentication phase. Driver-specific documentation will be added in this folder with the driver APIs themselves, for example:

- `auth-api.md` — driver OTP/login
- `profile-api.md` — onboarding, documents, approval
- `trip-api.md` — trip offer, accept, start, complete, cancel
- `online-status-api.md` — online/offline availability
- `earnings-api.md` — earnings and wallet

User API documentation belongs only in `docs/user/`.
